# Software Company

## Project Description

A simple website built using HTML and CSS as part of a collaborative software development project. The project demonstrates teamwork using Git and GitHub branches and Pull Requests.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/a-ghuneim/software-company.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## Git Workflow

- `main`: Main stable version of the project.
- `dev`: Shared development branch.
- `feature/*`: Separate branches for individual features.

Each student creates a feature branch, commits and pushes changes, then opens a Pull Request targeting `dev`. After review and approval, the PR is merged into `dev`. When development is complete, `dev` can be merged into `main`.

## Collaboration Evidence

Pull Requests and branches can be viewed in the repository's GitHub **Pull requests** and **Branches** sections.
